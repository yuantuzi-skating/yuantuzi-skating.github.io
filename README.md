# 袁兔子教练 · 一起滑向热爱

滑冰课程与每周课表的可交互网站，包含课程筛选、预约意向保存与取消、日历导出，并适配手机。

## GitHub Pages 发布

将本目录内容放在仓库根目录。在仓库 **Settings → Pages** 中选择 **Deploy from a branch**，分支选择 `main`，目录选择 `/(root)`。

首页是 `index.html`。页面使用相对资源路径，可直接发布到 GitHub Pages 仓库子路径，无需构建步骤。

## 体验版说明

当前课程与课表为可替换的示例。预约意向仅通过 `localStorage` 保存在当前浏览器，不会发送给教练，不占用真实名额；未接入后台、支付或通知服务。冰场、费用与正式课程安排需由教练确认。
